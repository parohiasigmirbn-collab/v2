# v2 # Sfântul Nicolae Theme

Temă WordPress block theme pentru Parohia „Sfântul Nicolae” din București.

## Caracteristici
- Design modern și responsive.
- Secțiuni pentru Home, Despre, Renovare, Program liturgic, Sacramente, Noutăți, Donații și Contact.
- Pregătită pentru RO / EN / EL.
- Structură compatibilă cu WordPress block theme.

## Instalare locală
1. Descarcă repository-ul.
2. Încarcă folderul în `wp-content/themes/sfantul-nicolae-theme/`.
3. Activează tema din WordPress Admin > Appearance > Themes.

## Instalare prin ZIP
1. Descarcă release-ul ZIP din GitHub.
2. În WordPress admin mergi la Appearance > Themes > Add New > Upload Theme.
3. Încarcă ZIP-ul și activează-l.

## Dezvoltare
- `theme.json` controlează stilurile globale.
- `templates/` conține layout-urile.
- `parts/` conține header/footer.
- `patterns/` conține secțiuni reutilizabile.
